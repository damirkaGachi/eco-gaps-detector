# Eco Gaps Detector

Модель для автоматического поиска противоречий (разрывов) между экологическими документами.

## Что делает

Сравнивает пары документов и находит разрывы 5 типов:
- числовые (10 тонн vs 5 тонн)
- временные (1 марта vs 15 февраля)
- обязательства (обязан vs может)
- штрафы (500 000 руб vs 250 000 руб)
- меры ответственности (дисквалификация vs предупреждение)
